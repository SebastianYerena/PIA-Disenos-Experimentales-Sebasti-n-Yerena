Descripción
Este repositorio fue desarrollado como parte del Producto Integrador del Aprendizaje (PIA) de la Unidad de Aprendizaje Diseños Experimentales.
Su propósito es organizar y documentar las actividades realizadas durante el curso, integrando tareas, laboratorios, scripts en R y demás evidencias académicas relacionadas con el análisis estadístico y los diseños experimentales.
Estructura del repositorio
📁 Tareas
Contiene las tareas y evidencias desarrolladas durante el curso.
📁 Scripts
Contiene los scripts elaborados en R para análisis de datos y ejercicios realizados durante el curso.
📁 Laboratorios
Contiene las prácticas y evidencias de laboratorio desarrolladas durante el curso.
Actividades realizadas
Durante el curso se desarrollaron las siguientes evidencias y actividades:
Evidencia de instalación de R y RStudio.
Evidencia de instalación y configuración de GitHub.
Evidencia de creación y organización de un repositorio en GitHub.
Evidencia de carga y administración de tareas en un repositorio en línea mediante GitHub.
